Install

From clone to desktop in one script.

SetupArch, CachyOS, Fedora

It checks first, then installs.

The setup checks every prerequisite and stops before touching the system if something is missing. --dry-run prints the plan without changing anything, and scripts/uninstall takes it all out again.

Idle, the backend daemon holds about 7 MB and uses no CPU: every state change arrives as an event.

Installation guide

kitty~
$ git clone https://github.com/cucu0628/vellum_shell.git \
    ~/.config/quickshell/vellum_shell
$ cd ~/.config/quickshell/vellum_shell
$ ./setup.sh --dry-run    # see the plan first
$ ./setup.sh              # install it
$ ./setup.sh --with-greeter   # optional login screen
